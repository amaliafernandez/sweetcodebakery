# Sweet Code Bakery 🍰

Una panadería artesanal que fusiona el arte de la pastelería francesa con la estética moderna de la tecnología. Sweet Code Bakery es un sitio web responsivo que showcasea productos premium, recetas exclusivas y la historia detrás de esta iniciativa innovadora.

---

## 📋 Descripción del Proyecto

Sweet Code Bakery es una panadería artesanal creada por dos amigos apasionados: una chef pastelera obsesionada con la precisión del hojaldre y un desarrollador de software. Desde 2021, transforman las pausas laborales en experiencias memorables, llevando pastelería fina a startups tecnológicas y estudios de diseño digital.

Este sitio web presenta:
- **Catálogo de productos**: Muestra los productos artesanales de Sweet Code Bakery
- **Sección comunidad**: Destaca creaciones para la comunidad tech.
- **Recetas**: Acordeones interactivos con recetas detalladas
- **Historia**: Narrativa completa del proyecto y su filosofía
- **Contacto**: Formulario para solicitar degustaciones personalizadas

## ✨ Características Principales

## 🚀 Cómo Usar

### Instalación Local

1. **Clonar el repositorio**
```bash
git clone https://github.com/tu-usuario/sweet-code-bakery.git
cd sweet-code-bakery
```

2. **Abrir en navegador**
    - Opción 1: Hacer doble click en `index.html`
    - Opción 2: Usar Live Server (extensión de VS Code)
    - Opción 3: Abrir con un servidor local (`python -m http.server`)

### Navegación del Sitio

| Página | Descripción |
|--------|------------|
| **Home** | Página principal con video y catálogo de productos |
| **Home (Info)** | Historia completa de Sweet Code Bakery |
| **Recetas** | Recetas detalladas con ingredientes y preparación |
| **Contactos** | Formulario para solicitar degustaciones |
| **Productos** | Página 404 personalizada (temporalmente) |

## 📱 Responsive Design

El sitio utiliza Bootstrap Grid System con breakpoints:

- **Mobile (xs)**: < 576px
- **Small (sm)**: ≥ 576px
- **Medium (md)**: ≥ 768px
- **Large (lg)**: ≥ 992px
- **Extra Large (xl)**: ≥ 1200px

Todos los elementos (imágenes, formularios, acordeones) se adaptan automáticamente.
